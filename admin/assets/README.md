# Сайт компьютерного клуба: бронь для гостей и панель администратора

- `index.html` — сайт для гостей (свободные места, бронь, отмена своей брони). Входа в админку на нём нет.
- `admin/` — панель администратора (выручка, зал, брони, смены, зоны и цены). Вход по email и паролю.
- `supabase/schema.sql` — база данных. `config.js` — адрес и ключ Supabase.

## 1. База в Supabase (один раз)
1. Создайте проект в новом аккаунте Supabase (регион Frankfurt, пароль базы сохраните).
2. **SQL Editor → New query** → вставьте весь `supabase/schema.sql` → **Run**.
3. **Authentication → Sign In / Providers**: выключите «Allow new users to sign up», чтобы чужие не регистрировались.
4. **Authentication → Users → Add user → Create new user**: email и пароль администратора, галочка «Auto Confirm User».
5. Сделайте его администратором клуба (SQL Editor, подставьте свой email):
   ```sql
   insert into club_admins (user_id, email)
   select id, email from auth.users where email = 'admin@example.com';
   ```
   Так же добавляются следующие администраторы.
6. **Project Settings → API Keys**: скопируйте Project URL и Publishable key в `config.js`.
   Секретный ключ (secret / service_role) никуда не вставляйте.

## 2. Сайт на GitHub Pages
1. GitHub → **New repository** (Public) → **Add file → Upload files** → перетащите все файлы и папки из этого архива → Commit.
2. **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save.
3. Через минуту-две адреса будут такие:
   - гостям: `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`
   - админам: `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/admin/`

## Как это защищено
- Гость видит только зоны, цены и какие места заняты. Имена, телефоны, выручка и смены ему недоступны: это закрыто правилами базы, а не только интерфейсом.
- Бронь проверяется на сервере: цена считается там же, двойная бронь одного места на одно время невозможна, на один телефон не больше 3 активных броней.
- Гость отменяет только свою бронь (секретный токен хранится на его телефоне).
- Админка без входа ничего не показывает, даже если кто-то узнает её адрес.

## Важно про бесплатный Supabase
Проект на бесплатном тарифе засыпает после 7 дней без запросов. Пока клуб работает и гости заходят на сайт, этого не случится.
Резервных копий на бесплатном тарифе нет.
